NewsRadar - Fullstack (Frontend + Backend)
=========================================

This archive contains a ready-to-run fullstack NewsRadar application:
  - frontend/ (React)
  - backend/  (Node.js, Express, MongoDB, Redis)

Instructions:
  1. Extract archive into your workspace or clone repo.
  2. Place backend/ alongside your frontend or replace frontend with your existing code.
  3. Configure .env in backend/.
  4. Start backend (npm install && npm run dev)
  5. Start frontend (cd frontend && npm install && npm start)
  6. Open http://localhost:3000
